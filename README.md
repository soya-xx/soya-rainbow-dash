# Soya Rainbow Dash

猫耳女仆 Soya 在宇宙彩虹路上躲陨石和光束的像素跑酷小游戏。

**在线试玩：** https://soya-rainbow-dash.pages.dev

整个游戏只有一个 `index.html`：画面、角色、字体、特效全部由代码实时生成，不加载任何图片或外部资源，下载下来双击就能离线玩。

## 操作

| 动作 | 键盘 | 手机 / 鼠标 |
|---|---|---|
| 跳跃（按住跳更高，空中再按一次二段跳） | ↑ / 空格 / W | 点右半屏 |
| 滑铲（空中按下是快速俯冲） | ↓ / S | 按住左半屏 |
| 冲刺（前冲时短暂无敌，按住会停在前方） | → / Shift / D | 在左半屏向右滑 |
| 暂停 | P / Esc | 切走页面会自动暂停 |

## 玩法

- 标题画面里 Soya 会自动躲完第 1 关，当作演示。
- 每关由几段攻击组成：陨石、预告后发射的光束、地板跳台和断裂。躲完进入 BOOST 加速，闪白后穿越到下一关；每过一关更快、更密。
- 被击中或掉进断裂会碎成像素，Game Over。跑得越远分越高，每过一关加 500 分；险些相撞会有慢动作并加分，连续险些相撞加得更多。最高分保存在浏览器本地。

## 技术说明

- 画面分辨率 320×180，按整数倍放大，保持像素锐利。
- 游戏逻辑以 60Hz 固定步长运行，坐标以 160×90 为单位，画面以 2 倍像素密度绘制。
- Soya 由身体帧、头部、头发链、猫尾链合成，合成后统一自动描边。头发和尾巴是一串跟随上一节的圆，带惯性和风。
- 标题演示的躲避时机在启动时自动求解，找每个动作“最晚仍能躲开”的时刻。

## 测试

在 `tests/` 目录下用 Node.js 运行，不需要安装依赖：

- `node headless.js`：标题演示连跑两轮不死；开局不操作会死并进入 Game Over；按演示时机能过第 1 关。
- `node probe.js 9`：第 10 关（最快最密）下逐个攻击搜索躲法，每种攻击都必须有解。参数 `0` 测第 1 关。
- `node beam-slide.js`：高位光束站着必须被打中、滑铲必须能钻过去。
- `node shots.js`、`node crops.js`、`node screens.js`：输出整屏截图、角色特写、游戏内界面截图（PNG）。
